# 测试计划执行原型

这是一个独立的前端交互原型，用于验证“计划用例执行历史 + 计划级 PDF 执行文档”的交互。入口复用当前 Veges 测试工作台，因此计划、用例、Bug、测试空间和周报等原有导航与工作流仍可在原型中操作。

运行 `npm ci` 后执行：

```bash
npm run dev -- --host 127.0.0.1 --port 5190
```

然后打开 `http://127.0.0.1:5190/test-plan-prototype.html`。端口被占用时，Vite 会选择其他端口。

## 体验路径

- `PLAN-24` 提供通过、失败、阻塞、跳过、未执行和没有执行元数据的历史结果。
- 打开用例详情可以查看快照、执行历史和记录执行表单。每次保存都会追加记录，最新记录决定最终结果，也可以用“未执行”保留历史并重置当前结果。
- 每条执行记录可以选择、粘贴或拖入最多 6 张 PNG、JPEG、WebP 或 GIF 图片。单张不超过 10 MiB，总计不超过 30 MiB；草稿关闭后仍保留，保存后会进入执行历史和 PDF。
- 快捷结果选择仍沿用工作台原入口；失败用例仍可直接创建 Bug，最近一次执行的实际结果和截图会带入 Bug 表单。
- 编辑、状态切换、删除计划、从计划移除用例、创建用例和原有确认弹窗均由真实工作台处理。执行记录保存后只更新当前工作台数据范围。
- “导出 PDF”始终导出整个计划，包含当前分页之外的用例、快照、最终结果和按时间排列的全部执行记录。报告按 A4 打印样式排版，浏览器中选择“保存为 PDF”即可归档。

所有数据都保存在内存模拟仓库中，刷新页面会恢复种子数据。原型不会启动 API、连接数据库或写入生产数据；它用于确认交互和排版，执行历史的生产持久化、并发控制、鉴权和服务端 PDF 生成不属于本原型范围。
