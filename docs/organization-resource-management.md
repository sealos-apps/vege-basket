# 组织资源管理验收

打开 `http://127.0.0.1:5173/`，点击左下角账号菜单中的「组织管理」，
在组织管理页面的「选择组织」中选择要管理的组织。以下操作均在此模块内完成。

## 测试账号与资源

- 管理账号同时具备「组织管理员」账号角色及目标组织的有效「管理员」或「所有者」成员身份。
- 建议使用其他成员拥有的测试项目和测试空间，避免把所有者权限误当成组织管理权限。
- 管理账号可保持「开发工程师」身份；测试空间管理不要求切换为测试工程师。
- 准备一名同组织的接收成员；测试空间直接添加的账号须具备测试工程师或组织管理员角色。

## 项目管理

| 操作 | 组织管理内的路径 | 预期结果 |
| --- | --- | --- |
| 新建 | 项目管理 → 新建项目 | 项目出现在当前组织列表 |
| 编辑 | 项目行右侧「…」→ 编辑项目 | 名称、简介、标签保存后重新打开仍一致 |
| 重命名 | 项目行「…」→ 重命名 | 当前组织列表立即显示新名称 |
| 状态、健康度 | 项目行铅笔按钮 | 状态及健康度更新 |
| 成员 | 项目行成员图标 | 从组织成员中直接加入、移除；新增无需确认 |
| 所有权转移 | 项目行「…」→ 所有权转移 | 发起后等待接收人在通知中心确认；确认后所有者变更，原所有者为普通成员 |
| 删除 | 项目行「…」→ 删除项目 | 输入完整项目名称才可确认；删除后项目消失 |

## 测试空间管理

| 操作 | 组织管理内的路径 | 预期结果 |
| --- | --- | --- |
| 新建 | 测试空间管理 → 新建测试空间 | 自动归属当前组织，组织内版本号不得重复 |
| 编辑 | 空间行 → 编辑 | 修改名称和版本号后列表更新 |
| 重命名 | 空间行「…」→ 重命名 | 名称更新，版本及组织不变 |
| 直接添加成员 | 空间行 → 成员管理 → 输入用户名、选择权限 → 直接添加 | 立即显示已加入，无需对方接受 |
| 成员权限、移除 | 空间行 → 成员管理 | 可切换只读/可编辑及移除，不能修改或移除所有者 |
| 组织归属 | 空间行「…」→ 调整归属组织 | 可转入同样有权管理的组织或取消归属；移出后从当前组织列表消失 |
| 删除 | 空间行「…」→ 删除测试空间 | 输入完整空间名称才可确认；删除后空间消失 |

跨组织移动要求空间所有者及全部已加入、待接受成员均为目标组织的有效成员。
不满足条件时应显示错误并保留原归属。取消组织归属后，未直接加入空间的原组织管理员
将失去对该空间的管理权限。

## 权限回归

仅有组织管理员账号角色、仅有组织管理员成员身份、其他组织管理员及已离组账号，
均不能管理不满足双重授权条件的他人资源。切换页面中的组织选择器不会授予权限。
上述管理能力不授予用例、计划、Bug、数据导入或项目集成配置的额外业务写权限。

自动验证使用 `npm test`；经明确授权后可用 `npm run test:resource-management`
执行隔离 PostgreSQL 集成验收，配置方式见 [runbook](runbook.md#organization-resource-management-verification)。
