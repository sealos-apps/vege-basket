# 信息架构

本文记录当前 Web 界面已经实现的信息组织、导航关系和主要用户流。界面事实以 `src/App.tsx`、`src/App.css` 和 `src/components/project-package-workbench.tsx` 为准；本文不描述 PRD 中尚未落地的能力，也不代替 API 或运维文档。

## 入口状态

应用进入可操作工作区前有三个界面状态：

| 状态 | 展示内容 | 进入下一状态的方式 |
| --- | --- | --- |
| 未登录 | 用户名与密码登录、注册、飞书登录；共享 AI 启用后密码注册必须来自有效项目邀请 | 登录或注册成功后加载工作区 |
| 工作区同步中 | 独立的同步等待页 | 当前用户和工作区数据返回后进入主界面 |
| 已登录 | 主导航、当前视图和账户菜单 | 退出登录后返回未登录状态 |

飞书 OAuth 登录结果优先从 URL fragment 读取，并兼容旧 query 参数；读取后会立即从地址栏清理登录状态和 token。项目邀请 token 仍通过 URL query 进入接受流程。

## 全局结构

已登录界面由主导航和工作区组成：

```text
工作区
├── 项目篮子
├── 我的待办
│   └── 消息（次级入口）
├── 草稿箱
├── Veges AI
├── 测试工作台（当前身份为测试工程师）
│   ├── 用例管理
│   ├── 测试计划
│   └── Bug 追踪
├── Bug 工作台（当前身份为开发工程师）
├── 组织管理（账户菜单，组织管理员或系统管理员）
└── 项目详情
    ├── 项目日记与待办
    └── 交付工作台
        ├── 交付事件
        ├── 事件级文档或操作
        └── 安装包组
            ├── 安装包条目
            └── 操作时间线
```

主界面不是多页面路由。五个主视图、项目详情和项目内子视图由客户端状态切换；返回关系依赖界面内的返回按钮，而不是浏览器路径。

### 主导航

桌面端主导航位于左侧，组织选择器是项目篮子、我的待办和 Bug 工作台的共同上下文。选择一个组织时，导航按“日常工作”“协作与交付”分组，日常工作包含项目篮子、我的待办和周报管理；草稿箱与 Veges AI 只在“个人项目”上下文出现，个人项目时侧栏只保留项目篮子、我的待办、草稿箱和 Veges AI。组织管理不属于侧栏的全局组织上下文：组织管理员或系统管理员从账户菜单“选择角色”下方进入，工作台内部自行加载并选择组织。周报管理不再显示重复的组织选择器：主界面直接继承侧栏组织上下文，测试工作台直接继承当前测试空间的归属组织；切换任一上游上下文前会保存正在编辑的草稿，未关联组织的测试空间显示空状态且不会回退展示其他组织的周报。通过周报链接进入时，系统先确认当前用户仍可访问目标组织，再切换上下文并打开指定周次。日常工作中的“我的待办”显示当前上下文内的未完成待办数，并只聚合该组织（或个人项目）中当前用户负责的待办、交付事件、Bug 和里程碑；消息中心作为页面内的次级入口保留邀请、关注和提及等提醒。

账户菜单显示当前账户信息，并提供账户设置、更新日志、角色切换、组织管理、明暗主题切换和退出登录。组织管理入口仅对组织管理员或系统管理员显示，且不受侧栏组织选择器限制。账户设置使用大尺寸单层对话框，打开后直接显示“个人资料”；桌面端左侧常驻“个人资料”“飞书通知”“登录安全”分类，右侧显示当前编辑区，窄屏则把分类移到顶部。显示名称、飞书通知和登录密码分别独立保存并在当前分类反馈；每日推送默认关闭，绑定飞书后可开启并设置 `Asia/Shanghai` 时区下的发送时间。

多角色账号登录后先选择本次身份，也可以从账户菜单切换。测试工作台只在测试工程师
身份下显示；开发工程师只能从独立的待修复入口访问分派给自己的 Bug，不能浏览用例
或测试计划。配置了 `VEGES_ADMIN_USERNAMES` 的系统管理员还可以维护账号角色。

## 测试工作台

测试工作台是与项目详情平级的独立全宽界面。测试空间负责成员和数据隔离，测试对象
表示被测应用、服务或产品，并可选择性关联用户有权访问的现有项目。

工作台使用独立左侧栏：品牌区下方切换当前测试空间，系统管理员通过品牌区齿轮打开
测试空间管理弹窗，集中完成空间新增、重命名、删除和成员权限维护。普通测试工程师
只能切换自己已加入的测试空间。周报管理使用当前测试空间的归属组织，不另设组织下拉；
测试空间未归属组织时不加载任何其他组织的周报。

- 用例管理按多级目录组织用例，记录前置条件、步骤、预期结果、类型、优先级和标签。
- 测试计划保存所选用例的不可变快照。执行结果为未执行、通过、失败、阻塞或跳过，
  首次执行会把草稿计划推进为执行中。
- Bug 必须关联当前测试空间的一条用例，创建时可按目录和编号、标题搜索选择；从失败的
  计划用例创建时绑定原用例并带入执行快照的环境、步骤和预期结果。测试工程师
  负责确认、分派、验证和关闭；开发工程师只能把自己的 Bug 推进到修复中和待验证，
  并添加处理评论。
- Bug 列表不受测试对象选择限制。测试端和开发端均可按用例、用例当前目录筛选，选父目录
  包含其子目录，目录选项展示完整路径以区分同名目录；无目录
  的用例归为“未分类”，无法自动回填用例的历史 Bug 单独归为“待补关联”。创建者通过
  编辑 Bug 补关联，已有有效关联不能直接更换。跨空间转移必须选择目标空间现有用例，
  清除原计划和执行关联，并在协作记录中保留原关联编号。
- Bug 筛选的“用例目录与用例”条件组依次提供目录、编号或标题搜索和用例选择。
  用例可选“全部用例”以仅按目录筛选；搜索只缩小候选，不作为 Bug 条件。组内目录和
  用例同时满足，再参与外层且/或组合。测试端候选来自当前空间完整用例库，开发端仅
  来自其可见 Bug。待补关联放在独立的“用例关联状态”条件中。
- 创建或编辑 Bug 时，“测试环境”优先以下拉方式展示当前测试空间已分配的环境名称和
  访问地址；未配置环境或历史 Bug 保留手工环境文本。Bug 详情可以复制或打开已配置的
  访问地址。Bug 创建者可删除自己的 Bug；测试空间 owner 和该空间中的 Bug 创建者可在
  Bug 详情修改空间版本号，其他空间设置仍仅 owner 可见。
- 新增 Bug 评论的文字草稿按“用户 + Bug”保存在浏览器本地；切换 Bug、工作台标签或刷新后分别恢复，提交成功后只清除对应 Bug 的草稿。图片和视频附件不会写入浏览器草稿，切换 Bug、离开工作台或刷新后需要重新添加；草稿保存失败时在输入区提示用户先复制内容。

### 顶部栏

顶部栏显示当前视图或项目名称，并按上下文提供操作：

- 项目篮子：新建项目。
- 项目日记：进入交付工作台；项目 Owner 还可管理项目模块、成员、邀请链接和项目群通知；支持 Markdown 导出。
- 交付工作台：返回项目日记、导出时间线、向当前事件添加安装包。
- 待办详情聚焦状态：隐藏顶部栏，为详情编辑留出完整空间。

进入交付工作台时，主导航整体隐藏，工作台使用完整内容宽度。

## 主视图

### 项目篮子

项目篮子是默认视图，用于浏览和维护全部可见项目。

- 搜索覆盖项目名、简介、标签、日记、待办和总结内容。
- 可按项目状态和标签筛选。
- 项目条目显示状态、访问角色、创建时间、名称、标签和可选简介。
- 点击条目进入项目详情。
- Owner 可修改状态、重命名、编辑简介、生成周总结、导出或删除项目。
- 无项目时展示创建第一个项目的空状态。

### 我的待办

我的待办聚合当前组织上下文（或个人项目）中当前用户直接负责推进的事项，不把关注、提及和邀请混入主列表。

- 事项类型包括待办、交付事件、Bug 和项目里程碑；默认只展示未完成事项。
- 按已逾期、今天、本周、更晚和未排期分组，并提供全部、逾期、今天、本周指标。
- 支持关键词、项目、事项类型和完成状态筛选；列表行保留事项类型、所属项目、截止日期和责任关系。
- 待办可直接标记完成，点击事项仍进入原有项目或工作台详情。
- 右上角“消息”进入原通知中心，处理项目邀请、关注事项、备注提及和其他提醒。

### 消息（我的待办次级入口）

通知中心按通知类型分组，并提供同类型数量筛选：

| 分组 | 主要信息 | 主要去向或动作 |
| --- | --- | --- |
| 项目邀请 | 项目与邀请方 | 接受、拒绝或忽略 |
| 指派给我的待办 | 项目、模块、优先级、截止日期、指派人 | 打开待办或标记已知 |
| 指派给我的交付事件 | 项目、事件类型、交付状态、指派人 | 打开项目或标记已知 |
| 明日到期 | 项目、模块、优先级 | 打开待办或忽略 |
| 备注提及我 | 待办、项目、提及人、备注摘要 | 打开待办或忽略 |

选择某类指标后仅展示该类通知；再次选择可回到全部。没有可见通知时展示与当前筛选条件对应的空状态。

### 草稿箱

草稿箱用于先捕捉、后归档未整理信息。

- 左侧或上方是快速捕捉输入区，支持成员提及；回车提交，`Shift+Enter` 换行。
- 待归档列表区分手动记录、飞书转发和 AI 分析中状态。
- 未处理条目可选择项目归档，或经确认后删除。
- 没有项目时，归档区域提示先创建项目，但仍保留删除入口。

### Veges AI

Veges AI 是统一的单一聊天界面。空白状态保留消息输入区和一行三张等宽示例提示卡，不展示功能 Tab 或助手选择器；窄屏保持单行并允许横向滑动。总结、待办提取和对话分析都是同一段对话中的能力，不作为可见 Tab、助手模式或独立导航；模型地址、Key 和模型名仍由服务端统一配置，页面不提供个人凭据输入。

- 空对话可显示一组简短的示例提示。点击后直接发送完整自然语言消息并进入同一输入处理链路，不预填输入框，也不新增功能 Tab、助手模式或独立入口；用户开始输入、添加附件或发送消息后隐藏。
- 用户通过明确的自然语言意图触发项目总结、工作区复盘、Markdown 待办提取或对话分析；发送时先短暂显示理解请求状态，由服务端模型在不读取项目或工作区事实的前提下完成语义分类。分类只接受固定的意图与日/周周期 JSON，含糊、否定、能力咨询和历史周期输入归为普通聊天；分类失败明确提示重试，不用正则猜测或静默降级。分类结果按 turn UUID、原始内容、附件和来源上下文幂等绑定，持久化回执不复制待办正文，浏览器也不能伪造能力路由。理解请求期间发送按钮变为停止，停止、切换上下文、删除当前对话或离开页面都会取消分类请求。选择 `@项目` 后，项目总结示例会使用当前项目名称，并发送语义明确的周报请求。
- 用户明确要求梳理当前日或当前周的工作区进展且没有选择 `@项目` 时，后端直接读取当前用户有权访问的项目、本人周期日记、与角色相符的待办活动、当前未完成待办和风险，再生成跨项目复盘与下一步建议。该能力不要求用户逐个选择项目或重新粘贴已有记录；“上周”等历史周期、能力咨询和普通闲聊不会触发工作区读取。已经选择 `@项目` 时，同类自然语言仍只使用该项目上下文。
- 输入框默认为两行多行编辑区，并在内容或上下文需要时自然增高；底部左侧提供文本附件和 `@`，右侧保留发送按钮。已选项目与附件显示在输入框内的可移除标签行，窄屏按相同顺序换行，不增加功能 Tab 或第二层工具栏。
- `@` 用于选择项目上下文。选择结果以独立的项目 ID 保存，并显示为可移除的上下文标签；项目名、附件名和附件正文都不用于解析权限或请求归属。
- 附件在浏览器内读取并随 turn 发送，不存在独立上传或对象存储附件库。一次最多选择 4 个 Markdown、纯文本、JSON、YAML、CSV 或日志文件；单个不超过 64 KiB，合计正文不超过 20,000 字符。服务端将原始文件名和正文加密保存在个人对话历史中，历史接口只返回安全的文件名和大小元数据。
- 一段已发送的对话固定为普通、项目或对话分析上下文，项目对话最多关联一个项目。更换或移除 `@项目` 会开始新的空白对话并保留旧对话历史；普通对话不隐式读取整个工作区。上一对话的在途响应先被停止并失效，不能更新新对话、历史、文档或待办候选。
- 附件读取期间禁用发送和上下文工具；更换项目、移除项目、重置对话或离开界面会使未完成读取失效，旧附件不能在新上下文中重新出现。
- 对话输入支持回车发送、`Shift+Enter` 换行；同一对话同时只允许一个生成中的 turn，发送按钮在生成期间变为停止。普通聊天与对话分析在对应助手消息中逐步显示正文，项目总结与待办提取只显示读取、生成、校验、保存等安全进度，不展示未完成的 JSON。断流时同一消息显示“正在确认回复结果”并从服务端恢复；失败或已停止状态也留在该助手消息内并提供重试，不在页面底部重复错误。普通回复默认只进入聊天历史；关联项目的已完成普通回复可明确点击“转为文档”，保存中不可重复提交，成功及刷新后显示“打开文档”。该文档只对创建者本人可见；保存期间切换对话时，迟到结果不能打开旧对话文档或把错误显示到新对话。
- 工作区复盘与项目总结、待办提取一样只显示准备、生成和保存进度，最终正文在服务端完成来源权限复查并提交 canonical turn 后一次显示。复盘 turn 会保留来源项目关系；失去任一来源项目权限或项目被删除后，该 turn 从历史和后续对话上下文中隐藏，重新获得全部来源权限后恢复。
- 明确的项目总结意图必须同时带有通过 `@` 选中的项目上下文；系统从输入措辞识别当前上海自然日的日总结或当前周一到周日的周总结。缺少项目上下文时留在输入区提示补充 `@项目`，历史日期请求按普通聊天处理；AI 返回后直接保存为独立文档，不增加确认步骤。
- 用户在输入框中粘贴 Markdown，并明确要求提取待办时，系统直接生成候选审核。AI 推断项目、模块、负责人、截止日期、优先级、标题和详情；用户可修改和勾选候选，确认后才批量创建待办。待审核候选没有推断出截止日期时，审核表单默认显示 `Asia/Shanghai` 当天且仍可编辑；AI 已推断的日期保持不变，已确认或已丢弃的历史批次不会补造日期。
- 待办候选审核对话框关闭后保留当前编辑，并提供继续审核入口。
- 明确的对话分析意图会开始一个无项目的对话分析会话，不在界面中暴露“对话分析”助手或模式选择器；之后重新选择 `@项目` 会开始新的项目对话。
- 对话历史是当前用户的个人导航，不与项目成员共享。登录后恢复最近可访问的会话；历史按今天、昨天、过去 7 天和更早分组，支持游标加载更多、切换、重命名和确认删除。项目失权后对应历史不可见，重新获得权限后恢复；删除聊天不会删除已保存总结或已创建待办。
- 待办候选审核仍按需打开，AI 结果不作为空态中的独立功能入口；空态示例仅是可直接发送的消息快捷方式。宽屏进入 Veges AI 时默认展开 AI 文档，历史与文档互斥占用同一个辅助面板槽位；窄屏默认保留聊天区，聊天、历史和文档按需全宽替换，不纵向堆叠。历史中的总结和待办结果可重新打开对应文档或候选审核；已确认或已丢弃的候选批次仅供查看，不能再次编辑确认。
- 没有文档时展示 AI 文档空状态；模型未配置或状态读取失败时在聊天界面统一阻断相关操作。

## 项目详情

从项目篮子、当前待办或通知进入项目后，默认落在项目日记视图。项目切换会重置当前项目内的临时选择，并按项目恢复尚未提交的待办草稿。

### 项目日记

项目日记是项目详情的主要上下文区：

- 可保存今日日记，也可为既往日期补记。
- 日期选择器标记已有日记的日期，并支持在相邻有记录日期间切换。
- 日记列表支持编辑、删除、公开/私密切换，以及标记或解除风险。
- 当前日期没有记录时显示对应空状态。
- 项目成员信息用于输入时的 `@` 提及。

### 项目待办

项目待办与日记处于同一项目上下文：

- 新建待办时可填写标题、详情、创建日期、截止日期、优先级、负责人和模块。
- 新建草稿按“用户 + 项目”保存在浏览器本地，切换项目后分别恢复。
- 待办列表支持关键词和组合条件筛选；条件可覆盖标题、模块、负责人、创建人、优先级、完成状态、确认状态、截止日期和创建日期。
- 打开待办后进入聚焦详情，查看或编辑完整字段、备注和图片；返回后恢复项目待办列表。
- 图片粘贴先显示上传中附件，完成后替换为服务端图片地址；上传失败只移除本批附件，并保留其间输入的文字和其他并发附件。
- 待办动态按时间展示创建、指派、确认、驳回、完成和重开事件，并标明操作人；日/周总结以这条事实流为主要周期依据。

### 项目配置

项目 Owner 可从顶部栏进入两个配置面板：

- 项目模块：创建或删除供待办归类的模块。
- 项目配置：按用户名邀请成员、复制邀请链接、移除成员，并配置项目飞书群通知开关和 `chat_id`。

协作成员可以查看其有权限的项目，并在项目、待办和交付事件中参与被授权的操作；Owner 专属入口不会对成员显示。

## 组织项目治理

拥有 `organization_admin` 账户角色，并在当前组织中担任所有者或管理员的用户，可以在“组织管理 → 项目管理”中治理组织下全部项目：

- 项目列表同一行展示生命周期状态、健康度、下一里程碑和待办统计，并支持按项目名、负责人、里程碑、状态和健康度筛选。
- 展开项目后显示按目标日期排列的里程碑；临期和逾期由当前日期计算，不作为持久状态保存。
- 项目治理设置可修改生命周期状态和健康度；“有风险”或“已失控”必须填写判断说明。
- 里程碑包含目标日期、负责人、验收标准、执行说明和关联待办；调整日期时保留原始目标日期。
- 里程碑状态在展开列表中直接切换；内容编辑弹窗不再承载状态修改，避免高频推进动作进入深层表单。
- 组织管理员可以创建、编辑、提交验收、确认达成、取消或重新打开里程碑。状态快操作只修改状态字段和对应时间戳，所有写入都绑定当前组织和项目，并记录加密审计事件。
- 该权限不包含项目删除、成员管理、飞书集成、日记或普通待办的越权修改；这些操作继续使用原项目权限。

## 测试环境维护

拥有 `organization_admin` 账户角色且在当前组织中担任所有者或管理员的用户，可以在
“组织管理 → 测试环境”维护环境名称、访问地址和所属测试空间。环境可同时分配给多个
同组织测试空间；保存前会校验地址格式和全部选中的空间归属。普通组织成员不显示未分配
环境，也不能维护该配置。

## 交付工作台

交付工作台是项目详情内的第二个信息层级，围绕“事件 → 安装包 → 操作记录”组织。

### 事件层

- 没有事件时先展示创建事件的引导空状态。
- 事件包含初始化安装或升级类型、标题、交付日期、交付人和草稿/交付中/已交付状态。
- 左侧事件列表支持切换当前事件，也可仅查看指派给当前用户的事件。
- 当前事件显示由操作及其关联待办计算出的完成进度。
- 删除事件会连同其安装包和记录一起删除，因此必须经过确认。

### 文档与操作层

- 事件可包含事件级文档或操作；安装包组下也可维护操作时间线。
- 文档编辑器使用单栏所见即所得画布，提供标题、强调、链接、列表、引用、代码和基础表格工具。代码块从工具栏菜单显式选择语言并按 Markdown fenced language 显示语法高亮；未指定或未知语言按纯文本显示，不自动猜测。链接在工具栏按钮旁的浮层中编辑，可再次点击按钮、点击外部、按 `Escape` 或使用关闭按钮退出。保存时仍以 Markdown 字符串进入现有接口。
- 操作可关联当前项目中已确认的待办，并同步维护待办完成状态和关联备注。
- 关联待办支持搜索和组合筛选；没有可关联或已选择的待办时分别显示空状态。
- 保存任一步失败时保留编辑对话框和当前输入，供用户修正或重试。

### 安装包市场

- 全局安装包市场继承侧栏当前组织作为唯一上下文；个人项目或已关闭市场的组织不显示该入口，也不会读取或展示全局包。项目交付工作台按项目所属组织解析策略，个人项目使用默认的完整市场策略。
- 组织管理使用独立的“安装包市场” Tab 配置总开关，以及相互独立的正式（Release）和测试（CI）开关。安装包目录不再选择渠道，而是维护一套同时作用于所有已开启渠道的可见范围：“显示全部安装包”“仅显示指定安装包”或“仅禁止指定安装包”。指定和禁止模式均提供按名称/ID、分类和当前配置状态筛选，并支持跨页保留、批量操作和分页，允许只配置一个包。保存时每个已开启渠道都必须保留至少一个可用包，如需全部关闭直接关闭对应渠道。CI 不支持的安装包不会出现在 CI 中，依赖包沿用父包在自身渠道的可见性。
- 先选择基础包、应用包或中间件，再选择正式/测试渠道、`amd64`/`arm64` 架构和可用版本。`sealos-oss` 保留正式渠道入口，不提供 CI 渠道。
- 基础包保留独立入口；`sealos-pro` 与 `sealos-oss` 的版本和对象读取复用 APPS 规则逻辑。
- 详情区展示 OSS 对象、版本、大小、临时下载链接和对象 Key。
- 用户先把一个或多个对象加入待添加清单，再统一写入当前事件。
- “展示全部包”只扩大已授权包规则下的对象匹配范围，不会绕过组织的包或渠道设置。
- 详情切换期间显示加载状态；没有对象、读取失败或尚未选择详情时分别显示对应状态。
- 只有最新一次查询结果可以更新详情，待添加条目的包、渠道和架构来自该详情的查询上下文。

### 时间线导出

顶部栏可导出当前项目的交付时间线。导出前先进入单栏所见即所得编辑对话框，确认后下载 Markdown 文件；空内容不能确认导出。

## 关键用户流

### 从线索沉淀到项目

```text
草稿箱快速捕捉 → 选择目标项目 → 归档 → 项目上下文更新
```

### 从项目记录到执行

```text
项目篮子 → 项目详情 → 记录日记或风险 → 新建待办 → 在项目或当前待办中跟进
```

### 从通知回到上下文

```text
通知角标 → 按类型筛选 → 打开项目或待办 → 处理内容 → 标记已知或忽略
```

### 维护交付记录

```text
项目详情 → 交付工作台 → 创建事件 → 从包市场选择对象 → 写入当前事件
→ 维护事件级或安装包级操作 → 关联待办 → 导出时间线
```

### 生成总结文档

```text
Veges AI 通过 @ 选择项目 → 输入明确的当前日/周总结意图 → 自动保存
→ 按需打开 AI 文档 → 列表或展开阅读
```

### 将项目回复转为文档

```text
Veges AI 通过 @ 选择项目 → 完成普通问答 → 点击“转为文档”
→ 服务端读取 canonical turn 并幂等保存 → 打开 AI 文档
```

### 复盘工作区进展

```text
Veges AI 不选择 @ 项目 → 输入明确的当前日/周工作区复盘意图
→ 服务端模型语义分类并消费幂等 receipt → 后端按权限读取跨项目事实
→ 显示安全进度 → 返回复盘和下一步行动建议
```

### 恢复个人 AI 对话

```text
Veges AI → 打开历史 → 选择一段可访问对话 → 服务端加载 canonical turns
→ 继续发送，或从历史结果重新打开 AI 文档/待办候选
```

### 从 Markdown 生成待办

```text
Veges AI 粘贴 Markdown 并输入明确的待办提取意图 → AI 推断候选字段 → 用户编辑并勾选
→ 确认创建 → 待办与活动事实一次写入
```

### 订阅飞书日报

```text
账户菜单 → 账户设置 → 飞书通知 → 绑定飞书
→ 开启每日推送 → 设置时间 → 保存通知设置
→ 次日收到昨日完成/重开活动与发送时的当前积压
→ 点击任务标题 → 必要时登录 → 打开对应项目的待办详情
```

## 响应式原则

- 宽屏使用固定侧栏和内容工作区；交付工作台隐藏侧栏并扩大内容区域。
- `1100px` 以下主导航改为页面顶部区域，项目详情、草稿箱、事件布局、包市场和文档编辑器改为单列；Veges AI 的历史或文档面板按需替换聊天区，不纵向堆叠多个面板。
- `760px` 以下导航采用两列，搜索、筛选、表单和待办工具改为单列；项目详情的辅助面板排在主要日记内容之前。
- 桌面端依赖固定高度和内部滚动的列表，在较窄视口改为自然文档流，避免嵌套滚动。
- 对话框宽度受视口约束；所见即所得编辑器在中小屏保持单栏，工具栏自动换行，正文独立滚动。
- 账户设置在桌面端使用左侧分类和右侧编辑区；窄屏使用接近全屏的单层对话框并把分类移到顶部，标题与操作区保持稳定，中间仅保留一个滚动区域。
- 按钮、筛选器和操作区在空间不足时换行或拉伸到可点击的整行宽度。

## 加载、空状态与错误

| 场景 | 当前反馈 |
| --- | --- |
| 初次加载工作区 | 独立同步等待页 |
| 后台同步或通用操作错误 | 工作区顶部同步横幅；错误状态使用错误样式 |
| 登录、注册或 OAuth 失败 | 登录面板内错误信息 |
| 项目、日记、待办、通知、总结为空 | 各视图使用与当前筛选或上下文对应的空状态文案 |
| 包市场读取中、无对象或读取失败 | 详情区分别显示加载、空结果和错误信息 |
| AI 请求中、断流确认、停止或失败 | 对应助手消息显示增量正文或明确进度；断流时原位确认服务端结果，停止/失败原位展示并可重试，不重复显示页底错误横幅 |
| AI 历史读取中、为空或失败 | 辅助面板显示骨架、空状态或重试入口；切换失败时保留当前对话 |
| AI 未配置或 Markdown 无有效候选 | 工作流显示不可用状态或可重试错误；不会创建待办 |
| 待办动态读取中、为空或失败 | 项目内事实流分别显示加载、空状态和重试入口 |
| 账户设置未绑定飞书或保存失败 | 未绑定时禁止开启每日推送；任一保存失败时停留在当前分类并保留输入，成功后就地更新状态 |
| 图片上传失败 | 移除失败批次的临时图片，保留最新编辑内容，并显示失败提示 |
| 交付操作或关联待办保存失败 | 保留对话框与输入，不继续执行后续更新 |

筛选造成的空结果与系统本身没有数据使用不同文案，用户可以据此判断是清空筛选还是创建内容。
